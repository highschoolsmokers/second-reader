# Worked example — Procurement ledger (Maxwell × Bruner essay)

A long-form critical essay on William Maxwell's *So Long, See You Tomorrow* read against Jerome Bruner's narrative psychology. Demonstrates the output of `build-reading-list` and the tier classification used by `procure-sources`.

## Procurement legend

- **TIER A — FAIR-USE PDF** — Article or chapter hosted on a university server for educational use. Direct download. Provenance is educational fair use, not a formal open-access license.
- **TIER B — PUBLIC DOMAIN** — In the public domain; downloadable from Project Gutenberg, Internet Archive, or similar.
- **TIER C — INTERNET ARCHIVE CDL** — Available via Internet Archive's Controlled Digital Lending. Readable in-browser. Not a source for a permanent PDF to ingest.
- **TIER D — PURCHASE OR LIBRARY** — No legitimate free full-text PDF. Buy, borrow, or request via ILL.
